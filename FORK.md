It is a fork of [derdilla/blood-pressure-monitor-fl](https://github.com/derdilla/blood-pressure-monitor-fl), shipped here as **Janan**.

I do not own the upstream app. That includes its name, icon, Play Store, F-Droid, Weblate, official GitHub Releases, and derdilla's signing key. GitHub Releases on **this** repo are only Janan builds, for [Obtainium](https://github.com/ImranR98/Obtainium).

The Android application id is `com.shenepoy.janan`. It installs next to the original (`com.derdilla.bloodPressureApp`). A store install and this APK cannot replace each other.
